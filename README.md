# Farouk Battikh

AI automation developer based in Tunisia. I build n8n workflows, LLM-powered pipelines and API integrations that take repetitive work off a team's plate, and I wrap them in a Next.js + Supabase interface when they need one.

I work freelance on Upwork, in English, French and Arabic.

## What I build

- **n8n workflows** - building, debugging and maintaining automations, from webhook triggers to multi-step AI pipelines
- **LLM integrations** - OpenAI, Claude and Gemini APIs, prompt design, structured outputs, AI agents and chatbots
- **API work** - REST APIs, webhooks, OAuth, data transformation between tools
- **CRM and lead automation** - Google Sheets, Airtable, Notion, Slack, Calendar
- **Web apps around automations** - dashboards and internal tools in Next.js, TypeScript and Supabase
- **Frontend** - animated marketing sites with Next.js, Tailwind CSS, GSAP and Lenis
